# SIRAI SFG2522

Маркировка, прочитанная по фотографии:

- SIRAI SFG2522;
- нормально закрытый клапан (NC);
- DN15;
- присоединение G 1/2 дюйма;
- рабочий перепад давления 0...8 бар;
- продолжительный режим ED 100 %;
- защита IP65.

В папке сохранен общий каталог электромагнитных клапанов SIRAI. Отдельный
заводской лист для обозначения `SFG2522` в открытых источниках не найден.
Напряжение и мощность катушки на фотографии не видны, поэтому подавать питание
до проверки маркировки катушки нельзя.

Источник общего каталога:
<https://www.heatingandprocess.com/wp-content/uploads/2016/09/SIRAI-General-Purpose-Solenoid-Valves.pdf>
