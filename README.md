# Документация оборудования по фотографиям

Папка собрана по фотографиям из переписки. В каждом каталоге сохранены исходные
фотографии и найденная эксплуатационная документация.

## Важные замечания

- Перед электрическим подключением следует сверять полную маркировку конкретного
  экземпляра, особенно выходное напряжение блоков питания и напряжение катушки
  электромагнитного клапана.
- Для SIRAI сохранен общий каталог серии, поскольку обозначение `SFG2522` не удалось
  сопоставить с отдельным заводским листом данных.
- Фотография белого зонда в папке HAOSHI сохранена как неопознанная. Нельзя считать,
  что это часть H-101, пока не будет фотографии маркировки или разъема целиком.
- Документы относятся к указанным семействам оборудования. Паспорт конкретного
  экземпляра с заводским номером, отметками приемки и поверки они не заменяют.
